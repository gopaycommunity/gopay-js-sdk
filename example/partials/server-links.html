Payment Links · gopay-js-sdk

sdk.createPaymentLink(goid, params)

POST /eshops/{goid}/links — store payment data behind a shareable URL. No payment exists until a customer opens it. The returned id is auto-filled below; it is a different identifier from the ten-character code at the end of url, and neither can be derived from the other.

—

Opening the link creates the payment and hands the customer to the hosted gateway to pay it, so nothing here charges anything. The payment stays observable from this SDK either way — once it exists, sdk.getPaymentStatus() reports its state as it would for any other payment.

sdk.getPaymentLink(goid, linkId)

GET /eshops/{goid}/links/{link_id} — read the link's state and the payment data it carries. Expiry is evaluated on read, so a link past its expires_at comes back active: false with stop_reason: EXPIRED — no need to compare timestamps yourself.

—

sdk.disablePaymentLink(goid, linkId)

DELETE /eshops/{goid}/links/{link_id} — stop the link from starting new payments. Not a delete: it still reads back, as stop_reason: FROM_API. Returns void, so this panel reports the follow-up read instead.

—

Disabling an already-inactive link is rejected with 409. A one-shot link that has been used is inactive too, so it cannot be disabled — it keeps redirecting to the payment it created. Cancel that payment to stop it.
