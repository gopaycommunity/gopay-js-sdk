Events & webhooks · gopay-js-sdk

sdk.listEvents(goid, params)

GET /eshops/{goid}/events — the eshop's events, newest first. Needs event:read. Leave the payment ID empty to list every type. The first event's id is auto-filled below.

—

sdk.getEvent(goid, eventId)

GET /eshops/{goid}/events/{event_id} — one event, e.g. the one a webhook named. Needs event:read.

—

sdk.verifyWebhook(rawBody, signature)

Checks the X-GoPay-Signature of a received webhook against GoPay's signing keys and returns the event. Needs shared:read. The signature exists only on a delivered webhook — it is a header of GoPay's POST to your webhook URL; getEvent() returns the same event unsigned, so its output cannot be verified here. Paste the body exactly as received: a single changed byte, re-indented JSON included, fails the check. On a test environment with demo-site's receiver, GET https://demo.<env>.dev.gopay.com/api/v1/test/webhooks?payment_id=… gives both: signature, and bodyBase64 to decode.

—

sdk.getWebhookPublicKeys()

GET /webhooks/public-keys — the JWK Set webhooks are signed with. verifyWebhook fetches and caches it itself. Needs shared:read.
